# Funding

This directory archives funding applications and supporting materials for the Caltech Book Club.

Applications are organized by the year the funding supports, followed by the funding program:

```text
funding/
  <funding-year>/
    <program>/
```

Each application directory should identify when the application was submitted and contain its justification, budget, and any other submitted materials. This distinguishes the funding year from the submission year and leaves room for applications to GSC and other programs each year.
